Gmail

  1. Click Copy signature above.
  2. In Gmail, open Settings (the cog) → See all settings → General → Signature → Create new. Paste.
  3. The logo won't come across, because Gmail only accepts images from the web. Delete the empty image box, click the image icon in the signature editor, and upload signature-logo.png from this folder. Click the logo and pick Small or Medium, whichever makes it about as wide as your name and title line.
  4. Scroll down and click Save changes.

Outlook (Windows, Mac or web)

  1. Click Copy signature.
  2. Open Settings → Mail → Compose and reply (or File → Options → Mail → Signatures on Windows desktop). Add a new signature and paste. The logo comes across with it.
  3. Set it as the default for new messages and replies, then save.

Apple Mail

  1. Click Copy signature.
  2. Open Mail → Settings → Signatures, add one with +, untick Always match my default message font, then paste.

If the logo ever shows up very large, set its width to 240 pixels in the app's signature editor.
